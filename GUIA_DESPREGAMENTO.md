# Asignatura incorporada: Despregamento de Apps. Web

181 preguntas originales basadas en la UD1 y UD2 enviadas en esta conversación.

## Distribución

- UD1: 53 preguntas: single 20, multi 8, short 14, match 5, order 2, develop 4
- UD2: 128 preguntas: single 49, multi 15, short 25, code 25, match 6, order 4, develop 4

## Criterios
- Preguntas test con opciones, respuesta y explicación.
- Preguntas breves y desarrollo con solución y criterios.
- Ejercicios de interpretación de configuración Apache y escritura de fragmentos.
- Casos contextualizados para que puedas responder sin recordar la práctica previa.
- Las cinco capturas corresponden a Directory/VirtualHost y mod_status y se muestran solo donde aportan valor.
- Todas se atribuyen a origen «temario»; no se han recibido audios de la profesora de esta asignatura.
- Las preguntas sobre configuración son para estudio: algunas configuraciones requieren también DNS, permisos y módulos activados para funcionar.
- El banco de revisión permite marcar preguntas y exportarlas sin cambiar la estética.

## Conservación de datos
No se modifican las claves de almacenamiento local ni los identificadores anteriores de DWCS. La nueva asignatura tendrá sus propios IDs DEP-U1/DEP-U2.

## Verificación
Ejecutar `npm ci`, `npm run check`, `npm run build`.
