# Material local de preparación — ESTUDIO / DWCS

Preparado a partir del temario y de las prácticas compartidas. Para abrir los ejemplos PHP, utiliza VS Code y PHP/XAMPP localmente. Para los archivos sin formularios puede servir `php archivo.php`.

Este paquete es para estudiar antes del examen. Solo se puede utilizar durante las pruebas cuando lo permita expresamente la profesora. No incluye acceso a Internet, GitHub ni servicios externos.

Los ejemplos son orientativos y no sustituyen el enunciado íntegro de las prácticas. Las pruebas de autenticación usan credenciales ficticias y no son sistemas de producción.

En el proyecto Angular, la práctica de código es un editor con soluciones modelo; **no se ejecuta PHP en el navegador**.
